# Changelog

## 0.5.1 — 2026-10-30

First public GitHub release. Added bilingual repository documentation, explicit MIT licensing for original work, third-party notices, private-data exclusions and Windows CI. Source bundles now include license and ignore files. Runtime behavior is unchanged from 0.5.0.

首次公开发布。补齐中英双语说明、原创代码 MIT 许可、第三方许可索引、隐私排除和 Windows CI；技能及程序包包含许可证。运行行为沿用 0.5.0。

## 0.5.0 — 2026-10-30

- Reusable `qq-wechat-task-materials` skill and JSON launcher.
- Exact named-group metadata lookup, explicit per-task admission and block management.
- Seven-day default search window, bounded expansion and preserved legacy blocks.
- WeChat 4.2.0.9 validated alongside 4.1.15.56; 66 automated tests.

- Media credentials removed from model-visible results and download manifests.
