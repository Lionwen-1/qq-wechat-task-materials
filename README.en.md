# QQ / WeChat task materials

[简体中文](README.md) · [English](README.en.md)

**Give your AI a group name and a task. Find messages, download files and images.**

- Find historical and recent messages in QQ and WeChat groups.
- Search task materials by group, date and keyword.
- Download chat attachments, group files and original images.
- Manage blocked groups.
- Use the Skill, CLI or MCP with different models.

For example:

> Find this week's lab requirements in the QQ "Course announcements" group, download the related files and original images, and make a to-do list.

## Get started

Download the [latest release](https://github.com/Lionwen-1/qq-wechat-task-materials/releases), follow the [installation guide](chat-task-bridge/README.md#安装一次), and load the [Skill](qq-wechat-task-materials/SKILL.md) in your AI. Then give it a group name and task.
