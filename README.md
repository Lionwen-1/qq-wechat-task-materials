# QQ／微信按需取材

[简体中文](README.md) · [English](README.en.md)

**告诉AI群名和任务，查消息、下载文件和图片。**

- 查找QQ、微信群聊中的历史和最新消息。
- 按群名、日期和关键词查找任务资料。
- 读取合并转发的聊天记录。
- 下载聊天文件、群文件和图片原图。
- 排除不想搜索的群聊。
- 支持Skill、CLI和MCP，方便不同模型调用。

例如：

> 从QQ「课程通知群」找这周的实验要求，下载相关文件和原图，再整理成待办。

## 开始使用

下载[最新版本](https://github.com/Lionwen-1/qq-wechat-task-materials/releases)，按[安装说明](chat-task-bridge/README.md#安装一次)完成接入，让AI加载[Skill](qq-wechat-task-materials/SKILL.md)，之后直接告诉它群名和任务。
